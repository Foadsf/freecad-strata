= Coming from Onshape
:description: Onshape's PDM, release management and document tutorials, mapped to Strata step by step.

Strata's panel follows Onshape's _Versions and history_ panel, and its release workflow follows Onshape's release management.
This page maps each Onshape help topic to the Strata tutorial that walks through the same steps in FreeCAD.

== What works differently

Strata keeps your files on your disk and works without a server. That changes a few things:

* *Merging is per document.* Onshape merges feature by feature inside a Part Studio. Strata decides per document: take, keep, keep both, or combine when one side only changed properties.
* *Approvals are by name, not by role.* Anyone who opens *Releases* can approve. There are no approver lists, release workflows with several steps, or notifications.
* *Sharing goes through a folder.* A network share, a synced folder or a Git server holds the shared history. There is no browser, no live co-editing, and no follow mode.
* *The Documents page is your file manager.* Strata has no labels, Onshape-style folders or search across projects.
* *No BOM table yet.* Part numbers and properties are stored in the documents, so FreeCAD's BOM tools and macros can read them.

These are the gaps against Onshape today. The xref:changelog.adoc[changelog] lists what each release added.
