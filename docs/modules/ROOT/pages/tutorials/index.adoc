= Tutorials
:description: Step-by-step guides for every Strata task, with screenshots and runnable Python examples.

Each tutorial takes a few minutes and builds on the xref:quickstart.adoc[quick start].
The screenshots use a small example project, _Gearbox_: a bracket, a shaft and an assembly that links them.

Coming from Onshape? xref:tutorials/coming-from-onshape.adoc[Coming from Onshape] maps each Onshape PDM and release tutorial to its Strata counterpart.

== The examples are tested

Every Python example in these pages is run inside FreeCAD by Strata's test suite (`tests/docs_examples_test.py`), and the output shown under each example is the output of that run.
If an example and Strata ever disagree, the test fails before the documentation is published.
