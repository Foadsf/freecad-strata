= Merge workspaces
:description: Bring the changes of one workspace into another: merge strategies, a choice per document, compare with base, and undo.

*Goal:* adopt the lighter bracket from the _Lightweight_ workspace in _Main_, while Main has moved on too.

*You need:* a project with two workspaces that both changed since they split. The xref:tutorials/workspaces.adoc[Explore an alternative] tutorial creates one.

This tutorial follows Onshape's https://cad.onshape.com/help/Content/Document/merging.htm[Merging workspaces and versions] help page, step for step.

== The situation

Since _Lightweight_ was created from _Main_:

* in *Lightweight* the base plate of the bracket became 6 mm thin and was renamed _Base plate (thin)_;
* in *Main* someone gave every document a part number and description (see xref:tutorials/properties.adoc[Part numbers and properties]) and made the shaft thicker.

So the bracket changed on both sides, and the shaft and the assembly changed only in Main.

== Open the merge dialog

[.steps]
. Switch to the workspace that should receive the changes, here *Main*. In Onshape terms Main is the _target_ and Lightweight the _source_.
. Click the workspace pill btn:[Main ▾] and choose *Merge into Main > Lightweight*. Or right-click Lightweight's node in the *Versions* graph and choose *Merge Lightweight into Main*.
. If documents have unsaved changes, Strata asks to save them first.

image::screenshots/09_merge.png[The merge dialog with a strategy and a choice per document,role=screenshot,width=680]

Each card is one document. It says what changed on each side since the workspaces split, and what will happen to it.

== Choose a merge strategy

The *Overall merge strategy* sets the default for every document, as in Onshape:

[cols="1,3"]
|===
| Strategy | What happens

| *Merge changes* (default)
| Takes what only Lightweight changed, keeps what only Main changed. Documents changed on both sides need a choice.

| *Keep Main*
| Records the merge but keeps every document as it is in Main. Use it to mark Lightweight as considered and rejected.

| *Replace with Lightweight*
| Every document becomes exactly what it is in Lightweight, including documents only Main changed.
|===

== Decide per document

The list on the right of each card overrides the strategy for that one document. This is Onshape's per-tab merge choice.

[cols="1,3"]
|===
| Choice | Result

| Keep Main | the document stays as it is in Main
| Take Lightweight | the document becomes Lightweight's version
| Keep both (copy) | for documents changed on both sides: Main's stays, and Lightweight's is saved next to it as `Bracket (Lightweight).FCStd`
| Combine both changes | offered when one side only edited the document's properties (part number, description, custom properties): the model comes from the side that changed it, the properties from the other side
|===

In the example the bracket shows *Combine both changes*: Lightweight changed the model, Main only its properties, so nothing is lost.
If both sides had edited the model, the card would show an amber warning and you would choose Keep Main, Take Lightweight or Keep both.

TIP: Strata merges whole documents, not single features. When both sides edited the same part's features, keep both copies, then copy the features you need from one into the other.

== Compare before merging

Click btn:[Compare with base] to open the comparison with the *common base*, the point where the two workspaces split, already selected on one side.
Switch either side between the base, Main and Lightweight, and use the 3D overlay to see the geometry change. See xref:tutorials/compare.adoc[Compare two designs].

== Merge

Click btn:[Merge]. Strata writes the merged documents, reloads the ones open in FreeCAD, and adds one history entry, *Merged Lightweight into Main*. Its details list the documents that changed.

The Versions graph shows Lightweight's lane joining Main.

== Undo the merge

Right after merging, a banner at the top of the panel offers btn:[Undo merge], as Onshape's _Revert_ link does.

image::screenshots/21_undo_merge.png[The Undo merge banner after a merge,role=screenshot,width=380]

Undo returns Main to its state before the merge, and the merge entry leaves history, so Lightweight can be merged again later.
Undo is possible until another change is recorded in Main or Main is synced. After that, restore the entry just below the merge instead; see xref:tutorials/go-back-in-time.adoc[Go back in time].
