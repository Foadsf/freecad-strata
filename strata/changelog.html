Changelog

0.3.0 (2026-10-13)

Onshape’s PDM and release tutorials, replicated in Strata; see Coming from Onshape.

New

  • Merge strategies as in Onshape: Merge changes, Keep target, Replace with source, with a choice per document and Compare with base.

  • A document changed on both sides where one side only edited its properties merges automatically: Combine both changes.

  • Undo merge right after a merge.

  • The Restore dialog lists the documents that would change; untick the ones to keep.

  • Properties…​: part number, description, company and custom properties for every document in one table, saved as one history entry. New command Strata_Properties.

  • Releases pre-fill the part number and description from the document’s properties at the released version.

  • Reject asks for a reason; a rejected revision can be fixed and resubmitted under the same label.

  • Revision history of a part number, Obsolete…​ with Mark revision as re-releasable, and Export…​ of a released revision to .FCStd and .step.

  • Revision schemes: letters (ASME Y14.35) or numbers, in Settings.

Fixed

  • Releasing a rejected revision again failed with refs/tags/pending/…​ changed meanwhile, and the revision stayed Rejected for good.

  • After Strata saved documents itself, FreeCAD still showed them as modified, so the next workspace switch or merge asked to save them again.

  • Colour arrays that FreeCAD renumbers on every save showed up as appearance changes.

  • A properties-only save was summarised as Rebuilt …​ instead of Properties: …​.

0.2.1 (2026-10-13)

New

  • Add-ons that host Strata choose its keys: configure(shortcuts={…​}), where None leaves a command without a key, and effective_shortcuts(). freecad-nxstyle needs this because NX uses Ctrl+Shift+D (Drafting) and Ctrl+Shift+Y (Layout).

0.2.0 (2026-10-13)

New

  • Keyboard shortcuts: Ctrl+Shift+H Versions and history, Ctrl+Shift+V Create version, Ctrl+Shift+D Compare, Ctrl+Shift+R Releases, Ctrl+Shift+Y Sync. None of them clashes with FreeCAD’s defaults.

  • Strata’s commands at the bottom of the Tools menu in every workbench.

  • Panel keys: arrow keys and Enter in History, Ctrl+F to search, Esc to clear or close.

  • An embedding API for add-ons that host Strata in their own interface: configure, on_ready, actions, activate_commands, theme.set_overrides. Used by freecad-nxstyle.

  • This documentation site.

Fixed

  • Strata did not start in a normal FreeCAD session: InitGui.py raised NameError, and the package was not declared as a workbench.

  • The panel could start hidden after it had been a background tab, or after FreeCAD closed. Only your own show and hide actions are remembered now.

  • Changing the theme no longer scans all of FreeCAD’s widgets, which could crash FreeCAD 1.1.4 with a spreadsheet open.

0.1.0 (2026-10-12)

First public release: automatic history in plain language, versions, workspaces, read-only views, restore of a project or a single document, comparison with a 3D overlay, per-document merge, releases with approval, and sync through a shared folder or Git server.
