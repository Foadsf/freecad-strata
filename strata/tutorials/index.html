Tutorials

Each tutorial takes a few minutes and builds on the quick start. The screenshots use a small example project, Gearbox: a bracket, a shaft and an assembly that links them.

Coming from Onshape? Coming from Onshape maps each Onshape PDM and release tutorial to its Strata counterpart.

  • Go back in time
    View earlier states read-only, restore the whole project or chosen documents.

  • Explore an alternative
    Create a workspace and switch between designs.

  • Merge workspaces
    Merge strategies, a choice per document, compare with base, undo.

  • Compare two designs
    See which features and parameters changed, and overlay both in 3D.

  • Assemblies and linked parts
    How projects keep an assembly and its parts consistent.

  • Part numbers and properties
    Part numbers, descriptions and custom properties for all documents in one table.

  • Release a design
    Release candidates, approval, reject and resubmit, revision schemes.

  • Revision history
    All revisions of a part number, obsolete revisions, export for a supplier.

  • Work as a team
    Share a project, open a colleague’s, sync and resolve a merge.

  • Automate with Python
    Runnable minimal examples for scripts and batch jobs.

The examples are tested

Every Python example in these pages is run inside FreeCAD by Strata’s test suite (tests/docs_examples_test.py), and the output shown under each example is the output of that run. If an example and Strata ever disagree, the test fails before the documentation is published.
